# clankit

This repo is public. Everything in it — code, docs, specs, commit messages —
must stay agnostic to my personal setup and work configuration.

- Never reference my machine's directory layout, account arrangement,
  employer, coworkers, or any workplace-specific workflow.
- Write skills, docs, and examples so they work for any user out of the box;
  describe behavior generically ("any per-directory account configuration")
  instead of naming my setup.
- This applies to commit history too: if something specific slips in, scrub
  it before pushing.
